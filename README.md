# Whippit Auktionshuset

Priserna på auktionshuset i WoW Forever (EU PvP Horde), från Whippits senaste scan.

- `index.html` är sidan.
- `data.json` är priserna. Den byts ut efter varje ny scan.

Lägsta pris kan vara en ensam listning. Snittet för 20 st säger vad du faktiskt får betala.
Sålda per dag är en uppskattning och är inte uppmätt i scannen.
